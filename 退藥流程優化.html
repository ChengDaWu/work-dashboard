CURRENT → OPTIMIZED

真正的差異：從多條作業路徑，收斂成單一決策模型

SYS.COMPARE.050
FINAL STATE
CURRENT STATE

現行流程

  • 停原醫囑、人工退藥、新增新醫囑分開處理。
  • 原餘藥與新首日量由不同操作路徑處理。
  • 帳務與實體藥品狀態容易分離。
  • 流程節點多，人工介入較高。
→
OPTIMIZED STATE

優化流程

  • 同一變更時間點，同時計算舊餘量與新需求。
  • Diff 直接決定補藥 / 預扣 / 不動作。
  • 帳務、單據、通知與實際補退藥形成閉環。
  • 決策規則單一，較容易自動化與稽核。
